## Опис / Description

Овој проект претставува компаративна анализа на повеќе модели за предвидување на ризик од мозочен удар со користење на техники од машинско учење.  
Во рамки на трудот се обработуваат реални медицински податоци и се адресираат клучни предизвици како што се нерамнотежа на класи (class imbalance) и недостасувачки вредности.

This project presents a comparative analysis of multiple machine learning models for stroke risk prediction.  
The study utilizes real-world medical data and addresses key challenges such as class imbalance and missing values.

## Модели / Models

Во трудот се анализирани следните модели / The following models are analyzed in the paper:

- Logistic Regression
- Random Forest
- Decision Tree
- Support Vector Machine (SVM)
- XGBoost

---

## Клучни аспекти / Key Aspects

- Data preprocessing pipeline  
- Handling missing values (Iterative Imputer)  
- Енкодирање на категориски податоци / Encoding of categorical data 
- Балансирање на податоци / Data balancing:
  - Oversampling  
  - Undersampling  
  - SMOTE  
- Hyperparameter tuning  
- Feature importance analysis  

---

## Резултати / Results

- Random Forest и SVM покажуваат највисока точност / Random Forest and SVM show the highest accuracy
- XGBoost обезбедува добар баланс помеѓу точност и интерпретабилност / XGBoost provides a good balance between accuracy and interpretability  
- Oversampling и SMOTE даваат значително подобри резултати од Undersampling / Oversampling and SMOTE give significantly better results than Undersampling 
- Age, glucose level и BMI се најважни фактори / Age, glucose level and BMI are the most important factors

---

## Заклучок / Conclusion

Трудот ја демонстрира ефективноста на машинското учење во предвидување на мозочен удар, со посебен акцент на важноста на правилна обработка на податоците и избор на модел.

The study highlights the effectiveness of machine learning in stroke prediction, emphasizing the importance of data preprocessing, model selection, and handling imbalanced datasets.
